## 2025-03-03 - [Missing Input Validation & Debug Mode]
**Vulnerability:** The application was vulnerable to 500 Internal Server Errors due to missing input validation in the `/predict` route when parsing form data via `request.form`. An attacker could exploit this by sending incomplete or malformed requests to cause a DoS by repeatedly triggering uncaught exceptions. Furthermore, the application had `app.run(debug=True)` enabled, which leaks internal stack traces to users on exceptions, escalating the risk to potential Remote Code Execution (RCE) via the Werkzeug debugger.
**Learning:** Hardcoded `debug=True` and unhandled input conversions (`float(request.form[...])`) without error-catching logic are critical security flaws that compromise server stability and disclose internal details.
**Prevention:** Always run Flask applications with `debug=False` in production. Ensure that all user inputs are strictly validated and that unexpected input types gracefully return a `400 Bad Request` instead of triggering server-side 500 errors.
