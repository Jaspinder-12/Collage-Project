## 2024-05-24 - DoS Vector via Unhandled Input Exceptions & Information Leakage via Debug Mode

**Vulnerability:**
The Flask `/predict` endpoint cast unsanitized form inputs directly to `float` without any error handling. Invalid inputs (e.g. non-numeric strings, or missing keys) would trigger unhandled Python exceptions (`ValueError`, `KeyError`), resulting in 500 Internal Server Errors. Since Flask's debug mode was enabled (`app.run(debug=True)`), these 500 errors could expose sensitive stack traces, paths, and internal variables to attackers (Information Leakage). Additionally, generating frequent unhandled 500 errors could be used as a simple Denial-of-Service (DoS) vector by exhausting server resources. Furthermore, machine learning models (`models/lr.sav` and `models/sc.sav`) were accessed via hardcoded Windows absolute paths (`D:\projects\...`), which breaks cross-platform compatibility and crashes the application on non-Windows hosts or in CI/CD pipelines.

**Learning:**
When accepting form data, especially when performing type casting (like converting strings to floats for machine learning inputs), it is critical to anticipate and handle malformed or malicious inputs gracefully. Relying on default framework error handling, especially with debug mode enabled in a production or publicly accessible context, exposes the underlying architecture and introduces security risks. Furthermore, hardcoded absolute file paths are a maintainability and deployment anti-pattern. Always ensure debug mode is explicitly disabled in the application entry point before deployment to prevent stack trace leakage.

**Prevention:**
Always validate and sanitize user inputs before processing them. Wrap input parsing and type casting logic in a `try...except` block, specifically catching expected exceptions like `KeyError`, `ValueError`, and `TypeError`. Return a generic 400 Bad Request response with a safe, non-descriptive error message ("Invalid input data") instead of allowing a 500 error to bubble up. Ensure `app.run(debug=False)` is used in production. Use cross-platform, relative path construction (e.g., `os.path.join(os.path.dirname(__file__), "models", "...")`) to reliably access local assets regardless of the deployment environment.
