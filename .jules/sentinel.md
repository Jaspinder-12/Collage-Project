## $(date +%Y-%m-%d) - Prevent DoS and Information Leakage via Unhandled Exceptions
**Vulnerability:** The `/predict` route converted form inputs (`request.form[...]`) directly to `float` without error handling. If a user submitted missing or malformed data, it raised `KeyError` or `ValueError` respectively. Combined with `app.run(debug=True)` enabled in production, this could lead to Denial of Service (DoS) by crashing the worker and Information Leakage by exposing full stack traces to end-users.
**Learning:** Never trust form input directly for numerical conversions in Flask, especially when mapping to ML feature arrays. Additionally, hardcoded Windows file paths break portability and can cause unhandled exceptions on deployment environments.
**Prevention:** Always wrap input parsing in a `try...except (KeyError, ValueError, TypeError)` block and return a safe, generic 400 Bad Request error. Never run Flask with `debug=True` outside of development environments. Use `os.path.join` for file path resolution to prevent `FileNotFoundError` due to OS-specific path separators.
