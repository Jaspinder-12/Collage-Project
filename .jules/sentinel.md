## 2024-04-01 - [Missing Input Validation and Flask Debug Mode Leakage]
**Vulnerability:** The `/predict` route in `app.py` was directly casting `request.form` parameters to `float()`. If any parameter was missing (KeyError), non-numeric (ValueError), or None (TypeError), it caused a 500 Internal Server Error. Furthermore, `app.run` had `debug=True` enabled, which could potentially expose sensitive stack traces, code snippets, and environment variables when these uncaught exceptions occurred. Also, file paths were hardcoded and may lead to issues.
**Learning:** Directly parsing input without `try...except` blocks creates easy avenues for Denial of Service and unexpected crashes. Compounding this, leaving debug mode on exposes application internals on crashes.
**Prevention:** Always wrap type casting of user input in a `try...except (KeyError, ValueError, TypeError)` block to fail gracefully (e.g., returning 400 Bad Request). Never enable `debug=True` in production or default configuration.
