## 2024-05-24 - Basic HTML5 Document Structure and Semantic Elements
**Learning:** Found older HTML files lacking proper structure (`<html>` without `lang`, missing `<head>` with viewport meta tag, and content placed directly in `<body>` without semantic landmarks). The absence of a `<meta name="viewport" content="width=device-width, initial-scale=1.0">` makes the application scale incorrectly on mobile devices, leading to a poor user experience. Missing `lang="en"` on the `html` tag reduces screen reader effectiveness by not explicitly declaring the document's language.
**Action:** Always ensure foundational HTML5 structure is present. Add `<html lang="en">`, define a `<head>` containing at least the `viewport` meta tag and `<title>`, and wrap the main content area in a `<main>` landmark. This ensures basic mobile responsiveness and screen reader compatibility before adding more complex ARIA attributes.
