## 2026-03-17 - Add Loading State to Form Submission
**Learning:** Adding a basic disabled loading state (changing "Predict" to "Predicting..." and disabling the button) to a traditional synchronous form submission provides immediate feedback that the backend is processing the request, improving confidence when submitting ML inference forms which may take some time.
**Action:** Consistently implement visual loading states on submit buttons to prevent double submissions and provide unambiguous status feedback during processing operations.
