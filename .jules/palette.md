## 2026-02-23 - Use Fieldsets for Long Forms
**Learning:** For forms with many inputs, visually and logically grouping related fields using `<fieldset>` and `<legend>` improves structural accessibility for screen readers and creates a more organized layout for users. In this app, item and outlet attributes were listed flat, reducing cognitive ease.
**Action:** Always group large related blocks of input fields within `<fieldset>` tags with descriptive `<legend>` elements to establish logical sections.
