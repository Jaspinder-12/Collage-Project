## 2024-05-24 - Basic HTML5 Document Structure and Semantic Elements
**Learning:** Found older HTML files lacking proper structure (`<html>` without `lang`, missing `<head>` with viewport meta tag, and content placed directly in `<body>` without semantic landmarks). The absence of a `<meta name="viewport" content="width=device-width, initial-scale=1.0">` makes the application scale incorrectly on mobile devices, leading to a poor user experience. Missing `lang="en"` on the `html` tag reduces screen reader effectiveness by not explicitly declaring the document's language.
**Action:** Always ensure foundational HTML5 structure is present. Add `<html lang="en">`, define a `<head>` containing at least the `viewport` meta tag and `<title>`, and wrap the main content area in a `<main>` landmark. This ensures basic mobile responsiveness and screen reader compatibility before adding more complex ARIA attributes.## 2024-05-24 - Formatting Raw ML Outputs for Readability
**Learning:** Raw machine learning prediction outputs passed to frontend templates (e.g., 3735.138) are often hard to parse visually and lack thousands separators, leading to poor user readability. The generic "Back" link is also non-descriptive for screen reader users and fails WCAG context rules.
**Action:** Use vanilla JavaScript (`Number.prototype.toLocaleString()`) to format raw numerical predictions on the client side without altering backend logic. Wrap the output in a strong tag with a status role (`<p role="status">`), and ensure navigation links are descriptive (`Return to Prediction Form`) to improve both visual clarity and accessibility.
