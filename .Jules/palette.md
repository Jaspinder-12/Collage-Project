## 2025-03-05 - Enhance Keyboard Accessibility with Custom Focus States
**Learning:** Adding accessible focus states without a framework (like Tailwind) requires pairing `box-shadow` with `outline: none` instead of just using `outline`. Relying strictly on `box-shadow` ensures better cross-browser visual consistency and allows for rounded corners (`border-radius`), unlike standard outlines, which can sometimes render inconsistently or as sharp squares on certain browsers. Using `:focus-visible` specifically for buttons prevents the focus ring from appearing during normal mouse clicks, maintaining a clean visual aesthetic for mouse users while still fully supporting keyboard navigation.
**Action:** When working with vanilla CSS applications, always use `box-shadow` with a subtle color (like `rgba(0, 123, 255, 0.5)`) and a transition effect for focus states instead of `outline`. Differentiate between `:focus` for form inputs (which always need it when interacted with) and `:focus-visible` for buttons to avoid intrusive outlines for mouse users.
